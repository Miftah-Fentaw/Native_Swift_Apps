# Security Policy

Native Swift Apps is a collection of learning projects. Security reports are taken seriously, especially for projects that store user data.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report it privately through GitHub's [private vulnerability reporting](https://github.com/Miftah-Fentaw/Native_Swift_Apps/security/advisories/new) for this repository.

Include as much of the following as you can:

- The affected project (for example `calculator/`)
- A description of the issue and its potential impact
- Steps to reproduce, or a proof of concept
- Any suggested fix

You can expect an acknowledgement as soon as possible. Once the issue is confirmed, a fix will be prepared and you will be credited in the release notes unless you prefer otherwise.

## Scope

These projects are intended for learning and are provided "as is" under the [MIT License](LICENSE). Review the code carefully before relying on any of them to protect real data.
